# 美术与动作阶段的人机协作——规格、审美与采购

## 结论

美术环节的人机分界线不在「好看不好看」，而在**可数字化的工程规格**与**不可数字化的审美**之间。阶段三（表现层）的工作量真相：约 80% 是代码（动画状态机、逻辑对接、tint 反馈、UI 数据绑定）——是能力卡流程的领土；纯人守的只剩四个词：风格、自然度、帧感、爽感。

## 正文

### 美术验收句的写法：拆成两半

| 美术需求 | 数字化部分（AI 可写验收句） | 不可数字化（人判断） |
|---------|---------------------------|---------------------|
| 哥布林模型 | glTF / 高 1.2m / 脚底原点 / 贴图 1024 / 面数 <5k / 命名 `goblin.glb` | 像不像、风格配不配 |
| 受击白闪 | flash 1→0 衰减 / tint 公式 / 时长 0.2s | 闪得舒不舒服 |
| UI 正式化 | 布局像素 / 字号 / 对比度 ≥4.5:1 | 视觉层级 |
| 动画 | 播放速度 / 状态机转换条件 / 根运动对齐 | 打得顺不顺 |

### 人机分工模型

```
人（美术指导 + 甲方）              AI（美术生产线）
① 定风格方向                      ④ 批量生成（Midjourney/即梦）
② 从变体里挑（20 选 1）           ⑤ 规格化处理（去背/缩放/量化调色板/坐标归一化）
③ 说清要改什么                    ⑥ 技术接入（spawn 替换/动画状态机/tint 系统）
                                  ⑦ 一致性检查（命名/尺寸/引用）
```

关键细节：**挑选时必须说清「为什么」**——「第 3 张对在低饱和」说出口的瞬间，判断变成可复用规格，写进下一批 prompt。风格漂移的解法不是技术，是把每次审美判断沉淀成文字（= ADR 的美术对应物）。

三人零美术经验团队的现实路线：人的角色是美术指导不是画师；素材可优先用 Kenney/Quaternius 等 CC0 库（风格天然统一、免费商用），生成工具作补充。

### 表现层模块版图：越靠近代码 AI 参与度越高

| 模块 | 客观:主观 | AI 包办 | 人守 |
|------|----------|--------|------|
| 模型 | 5:5 | 规格校验、坐标归一化、入库 | 风格 |
| 骨骼 | 9:1 | 结构/绑定权重校验 | 几乎不用守 |
| 动画文件 | 7:3 | Mixamo 采购 + 接入 | 自然度 |
| **状态机/逻辑对接** | **9:1** | **全代码，卡流程领土** | 帧感微调 |
| 特效（hanabi） | 7:3 | 参数 + egui 调参面板（反馈闭环最短） | 爽感 |
| UI | 6:4 | 布局 + 数据绑定 | 视觉层级 |

**逻辑与动画是两套时间**，中间的翻译层是代码且有验收句：`Attack.cooldown 触发 → 切 attack 动画`、`伤害结算帧 = 动画命中帧（±2 帧）`、`死亡先播动画再 despawn（延迟删除）`。打击感 = 动画帧 + 特效帧 + 音效帧三者对齐，差 2 帧人就感觉「软」——这个微调只能人做。

### 动作设计 = 采购 + 组装，不是创作

对波次生存这类项目，动作需求表极短（玩家 idle/run/slash，怪 idle/run/attack，共 6-7 个基础动作，全是人形标准动作），且 Mixamo 免费动作库可一键绑骨——**动作设计是「点菜」不是「做菜」**。

原创动作的误区：没人从空气里设计动作。行业的真实做法是**参考驱动**：
1. 找参考游戏（Hades 的挥砍：斜切、快进慢出、带拖尾）
2. 拆成可说的需求——到这步就是全部「设计」
3. AI 翻译成采购单（Mixamo 关键词 + hanabi 拖尾参数）

人的真正输入是玩家语言的真实感受（「没劲儿」「跑起来飘」）——玩了几十年游戏，这是最资深的领域。团队连参考都定不下来时：三人各玩 20 分钟同类游戏，记「哪个游戏的哪个动作最舒服」。

### 占位图：进度解耦 + 判断纯度

占位图的职责只有三条：能看见、能区分（颜色编码身份）、能定位（大小对）。它让两条线并行：

```
玩法组：占位图钉死玩法（Nova、敌人分化）→ 回归测试保护
美术组：按自己节奏出图 → 放进 assets/ → 按卡逐个替换（有验收句兜底）
```

自动化占位更进一步：spawn 引用语义名（`goblin.glb`），文件缺失时程序化生成占位 + 打日志——真资产放进目录的那一刻自动换上，日志即美术进度仪表盘。

一个反直觉的价值：**越早的阶段画面越糙，玩法反馈越准**（灰盒期说「第 3 波太密」是玩法反馈；精致画面会说「感觉不错」掩盖数值问题）。先用最便宜的可视化验证「好玩」，再把美术预算花在已被证明好玩的东西上。
