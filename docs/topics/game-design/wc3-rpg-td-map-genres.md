# 魔兽 RPG 塔防地图品类调研——循环圈与「一基座多地图」生态

## 结论

魔兽 RPG 塔防 20 年生态的答案分两层：**玩法层**，循环圈（绿色循环圈 / 水之TD）的本质差异是「漏怪不死、绕圈施压、场上活怪存量做失败线」，把经典 TD 的一次性漏怪扣血换成了持续累积的软压力，从而撑得起英雄塔养成这条纵深；**架构层**，魔兽生态的本质是「一个通用战斗 runtime（单位/攻甲类型/光环/英雄/金木人口）+ 数据驱动的 Object 定义层 + 触发器脚本层」宿主了上千张玩法完全不同的地图。我们要复刻的是这个**分层**，而不是某张图的数值。

## 一、魔兽 RPG 生态为什么能「一基座、千张图」

World Editor 把「做游戏」拆成了三层，每层的使用门槛依次升高，但都**不需要改引擎**：

| 层 | 工具 | 内容 | 类比 |
|----|------|------|------|
| 场景层 | Terrain Editor | 地形、装饰物、Region 触发区 | 关卡数据 |
| 对象层 | Object Editor | 从模板单位克隆改字段：单位/技能/Buff/升级/物品——纯数据 | 定义表（塔/怪/技能=一行行数据） |
| 逻辑层 | Trigger Editor（GUI 事件-条件-动作 → 编译成 JASS 脚本） | 波次流程、特殊规则、胜负判定 | 玩法编排代码 |

地图文件 = 地形 + 对象数据 + 脚本 + 导入资产的自包含包，引擎宿主任意地图。于是同一套 runtime 长出了塔防、军团战争、守卫剑阁式 RPG、DOTA——这是「后续拓展多个不同玩法」的历史验证。

对自研的直接映射（详见 [[topics/game-design/loop-td-game-proposal|需求草案]]）：**引擎底座（Bevy）→ 战斗 runtime crate（单位模型/攻甲类型表/光环 Buff/技能框架/波次导演/金木人口）→ 地图 bundle（路径 + 定义表 + 波次表 + 规则参数）**。一张「地图」= 一份数据 + 少量编排代码，runtime 不随玩法变。

生态另一半是**平台与长线运营**：KK 官方对战平台等延续了大量经典图的生命线；绿色循环圈靠海量版 / 外传等版本迭代 + 指尖魔兽手游化活了十几年。启示：单张图的寿命 = 养成纵深 × 版本更新频率，二者都要求塔/波次内容是**数据可扩**的。

## 二、塔防 RPG 主要品类图谱

| 品类 | 代表图 | 核心机制 | 策略焦点 | 漏怪规则 |
|------|--------|----------|----------|----------|
| 经典固定路径 TD | 各类「xx 防御战」 | 怪沿固定路径走，塔自动攻击 | 塔位与升级顺序 | 漏怪扣命，一次性 |
| **循环圈** | **绿色循环圈、水之TD** | **怪物绕圈循环，漏怪不死持续绕行** | **塔位 + 英雄塔养成 + 经济运营** | **活怪存量逼近上限（绿圈为 100）失败；水TD 漏到队友区** |
| 迷宫 TD | 各类迷宫图 | 自由建塔「摆迷宫」延长路径 | 迷宫拓扑规划 | 漏怪扣命 |
| 宝石 TD（迷宫变体） | Gem TD | 每回合随机 5 石选 2 落地，走固定步数后两两合成高级塔 | 合成路线 + 迷宫 | 漏怪扣命（Boss 计漏数） |
| 元素 TD | Element TD | 采元素 → 元素组合解锁塔；存钱吃利息 | 元素树 + 利息经济 | 漏怪扣命 |
| 军团战争 | 军团战争 5 | 造「兵」自动战斗防守 + 花钱给对手发兵，攻防一体对抗 | 兵种克制 + 发兵时机博弈 | 漏怪扣己方国王血 |
| 守塔 / 生存 RPG | 守卫剑阁、神之墓地 | 可操作英雄养成 + 副本化防守 | 英雄 Build + 装备 | 多样（据点/复活次数） |

循环圈被视为塔防 RPG 化的起源玩法之一——正是「绕圈」这个路径拓扑改动，让塔防装得下养成和扮演元素。

## 三、循环圈解剖（主样本：绿色循环圈，辅证：水之TD）

### 3.1 地图与路径

- 怪物从入口进入后**不冲终点**，沿固定循环路径一圈圈绕行；玩家在路径两旁建塔。
- 多人图（水之TD 4 人）每人守自己的一段/一圈，公共区域共享。
- 圈形拓扑的意义：**塔的火力覆盖时间是弹性的**——杀得慢怪就多绕几圈，杀得快就少绕。这天然形成了「软失败缓冲」，也放大了减速/控制类塔的价值（拖住怪=多绕一圈=多一轮输出窗口）。

### 3.2 漏怪规则与失败条件（品类定义级差异）

- 绿色循环圈：漏过的怪**不死不出局**，继续绕圈；**场上存活怪物总数超过 100 → 失败**。压力是存量累积的，不是一次扣血。
- 水之TD 新版：取消漏怪扣血，改为**漏到队友区域**——协作维度（帮队友收拾烂摊子）成为核心体验。
- 失败条件的三种可选形态（对我们都是候选）：A. 活怪存量上限；B. 绕满 N 圈消失并扣命/扣分；C. 漏到下个玩家区（需多人）。
- BOSS 关附加**限时击杀**：规定时间内杀不掉 BOSS 直接判负——防止玩家靠无限拖延磨死 BOSS，逼输出检验。

### 3.3 塔体系：基础塔 → 英雄塔

- **基础塔**：点击空地建造、点击已建塔升级/回收。数值塔，构成前期与经济基础。
- **辅助/光环塔**：减速（集中放、控场）、腐蚀（减甲，配合点杀）、增伤光环等——循环圈里「功能塔」价值远高于纯 DPS 塔，因为绕圈放大了每一秒控制的效果。
- **英雄塔**（循环圈的灵魂）：以英雄命名的塔（后羿、吕布、狂狼、人马、电法、风神、战神、火魂、渔人……），带完整养成：

### 3.4 英雄塔养成纵深

| 养成面 | 绿色循环圈实例 |
|--------|----------------|
| 塔基 | 「另类塔基」决定英雄塔底子，是 build 的起点（人马塔拿另类塔基出死亡） |
| 技能升级顺序 | 每座英雄塔 4 技能，「3241」这类加点顺序是攻略核心知识 |
| 天赋 | 用资源开启/max（狂狼「-s 和还俗无法开天赋」；「木头优先给缓速和通灵天赋」） |
| 属性加点 | 沿用魔兽英雄三属性模型（渔人塔减防鱼「全智力加点」） |
| 成长上限 | 外传引入英雄塔成长属性 MAX 值 |
| 装备/神器 | 英雄塔带装备栏；神器是后期追求（「卡 52 波彩龙刷黑龙否则经济不够、神器弄不齐」） |
| 羁绊 | 特定英雄组合触发羁绊加成（火影羁绊、周瑜羁绊） |
| 流派 | 同一座塔多流派（渔人：减防鱼/加速鱼/加攻鱼应对不同波） |

### 3.5 经济：金 / 木 / 人口（沿用魔兽资源模型）

- 双币：**金币**（建塔升级）+ **木材**（开天赋、买人口、换钱——开局建议木换金）。两者兑换关系本身就是运营决策。
- 收入：击杀掉落、波次奖励、地图上可打爆的**小金矿**、特定波次「卡波」刷经济（52 波彩龙刷黑龙）。
- **人口**：塔数量上限，用木材购买——限制无脑铺塔，逼质量路线。

### 3.6 波次与怪物特性设计

- 长波次表（海量版 50+ 波），**关键波**设计是节奏骨架：11 波白狼/吕布、15/23 波神圣怪、21 波骷髅、29 波魔法怪、31 波、52 波彩龙——关键波=检验特定 counter 的考试。
- 怪物特性标记体系（沿用魔兽攻/甲类型 + 自定义）：神圣护甲（需对应攻击类型 counter，出怪提示「多神圣/少神圣」影响备战决策）、光环怪（给周围怪加成，须点杀）、加速/加攻变种、魔法免疫类、治疗怪、快速怪、飞船（空中）波。
- **出怪预告**（下波是什么特性）是必备 UI——备战期决策的输入。

### 3.7 周边系统（循环圈的「RPG 化」配件）

- **挑战**：间隔开放的可选 BOSS 挑战，高风险高收益。
- **挖宝**：特定波次的寻宝小玩法，时机表本身是攻略知识。
- **无尽模式**：通关后继续，比分数。
- **多人协作**：养人（让经济/资源给队友）、卡 BOSS、水式「漏怪互助」。
- **计分**：击杀数等维度的总分 + 结算。

### 3.8 好玩在哪（机制 → 体验的因果）

1. **存量压力 + 全程在场**：漏怪不消失，玩家的每个失误都留在场上可见地绕圈——焦虑感具象化，翻盘也可见（慢慢清存量）。
2. **弹性难度**：杀得快=少压力，杀得慢=压力滚雪球但仍有救——同一局内难度自适应。
3. **控制 > 输出**：绕圈拓扑让减速/减甲/光环的价值指数化，功能塔组合深度高。
4. **养成纵深**：英雄塔 8 个养成面 + 羁绊 + 流派，单局目标从「守住」扩展到「养出什么 build」。
5. **知识社区化**：加点顺序、卡波时机、挖宝表——可分享的攻略知识是地图长寿的社区燃料。

### 3.9 版本演化（长线内容运营样本）

绿色循环圈历经原版 → 海量版（v4.6.x）→ 外传（MAX 成长、英雄塔扩容）→ 指尖魔兽手游移植；水之TD 出到水TD4 + 高清重制版（2020）。共同点：**底层规则稳定，塔目录/波次表/养成面持续扩充**——再次印证「内容=数据」的架构价值。

## 四、对自研的两条启示

1. **基底层（跨玩法复用，值得上收）**：单位域模型（属性/攻甲类型）、光环与 Buff、按实体技能框架（[[decisions/0011-generic-per-entity-skill-framework|ADR-0011]] 已验证）、统一伤害管线、波次导演、金/木/人口资源、命令卡 UI——大半已在 warden 有可复用实现或范式。
2. **玩法层（每张「地图」不同）**：路径拓扑（圈/迷宫/直线）、漏怪规则（存量/扣血/漏给队友）、塔目录与养成深度、经济参数、周边系统取舍。**这些必须做成数据/配置可换，而不是写死在系统里**——这是「一基座多玩法」的分界线。

## 待验证清单

- 绿色循环圈各版本「绕圈增益」（部分版本漏怪每绕一圈提速/强化，用于反无限拖延）——未找到一手出处，按机制自设计时需自定并平衡。
- 波次推进方式（自动计时连发 vs 手动开始）：印象中主流循环圈为自动推进（故有「卡波」技巧），未逐版本核实，立项时按决策点处理。
- 神圣护甲等特性的具体克制数值表——实现时应自建攻/甲表（参考魔兽克制思想即可），不必复刻。
