# 美术风格与管线基础——维度、粒度、统一性与物理的关系

## 结论

四条可迁移的认知：① 2D/3D 是最早锁定、最难反悔的「第一决策」，它决定整个技术底座的形状；② 风格统一的本质是「共享约束」（同源或同规范），不是单个资产的精致度——「统一但粗糙」远胜「局部精致但互相打架」；③ 资产要按套装组织、按变体派生，与 ECS 组合规则同构；④ 物理引擎跟着玩法实际用到的维度走，「3D 底座 + 平面玩法」是最优组合而非浪费。

## 正文

### 风格决策的坐标系

三个轴同时起作用：

- **技术轴**：2D 像素/手绘 → 2.5D 贴片 → 3D 低模 → 3D 高模。难度排序（按无美术团队的采购+AI 路线）：3D 低模 ≈ 2D 像素 < 3D 高模 << 2.5D（素材最难采购、生成一致性最难）
- **写实↔风格化轴**：越风格化越便宜且越耐看——写实风的成本大头在贴图细节（AI 和 CC0 都最难覆盖），且会随硬件时代过时；风格化不绑时代
- **统一性轴**：玩家的容忍度排序是「统一但粗糙」>「局部精致但互相打架」。**风格不是每个资产的属性，是资产之间的关系**

波次生存品类的美术第一任务是**可读性**（同屏 50+ 实体，0.2 秒分辨我/怪/掉落/危险）：轮廓优先于细节（剪影不同 = 混战不认错）、色彩即类别（暖=玩家、冷=环境、高亮=可交互）、怪待机动画幅度小（视觉噪音控制）、特效克制。可读性标准和风格正交，且可数字化（色板检查、轮廓对比度）——是美术里最容易被卡流程接管的部分。

### 2D/3D：不可逆的第一决策

锁定的是五根互相咬合的柱子：渲染管线、物理引擎（rapier2d/rapier3d 是两个独立 crate，非同引擎两模式）、资产管线、Transform 用法、动画体系。中途换维度 ≈ 推倒重写。

立项三问收敛：① 相机视角（俯视/横版→2D 或伪 2D 可行；自由视角→必 3D）；② 核心玩法吃不吃 Z 轴/空间深度；③ 团队/采购的美术资源在哪边（3D 的 CC0+Mixamo 生态最成熟）。

两层 flexibility：**底座维度早定，资产精致度晚定**（占位方块 = 最简 3D 资产）；3D 底座向上兼容 2.5D 表现（贴片挂面片），2D 底座升 3D 是死路——3D 底座是「买期权」。

物理引擎决策表：2D 俯角只要碰撞 → 不用引擎手写 AABB（Vampire Survivors 路线）；2D 要推挤/重力 → rapier2d；**3D 底座 + 平面玩法 → rapier3d + Kinematic（wave-survival 现路线，借碰撞检测不用全动态模拟）**；真 3D 玩法 → rapier3d 全动态。Kinematic 刚体间不产生接触事件——这是 wave-survival 卡 5 改用距离判定的根因。

### 生产粒度：单品 → 套装 → 模块化

| 层级 | 定义 | 要点 |
|------|------|------|
| 单品 | 一个文件 | 最危险的采购单位：五个怪五个作者 = 造型语言打架，量化救不了形状 |
| **套装（Kit）** | 共享约束的一组资产 | 同头身比/基本体构成/色板/剪影密度——遵守约束即可添加成员（含 AI 生成的） |
| 模块化套件 | 可互换的标准件 | 统一网格/接口尺寸，波次生存用得浅（固定竞技场），Boss 房/障碍物才需要 |

变体派生 = 一个基础模型撑一族敌人（换色板槽位 + 缩放 + 部件替换），与 ECS 数值分化**对称设计**（快而脆↔细长绿 / 慢而硬↔粗壮红）。落地形态 = spawn 读「敌人定义表」，每行 = 组件数值 + 视觉参数 + 武器名——「新怪 = 新组件组合，老系统零改动」在美术层的延伸。

### 部件替换与武器插槽

机制核心是**锚点（socket）**：武器不焊死在模型里，运行时作为子实体挂在骨骼锚点（如右手掌 hand_r）上——骨骼播动画武器自动跟随，武器零动画代码。建模约定：武器原点做在握把处。

价值不仅在省美术量：**武器是行为预告**——玩家扫一眼武器就知道这怪怎么打（木棒=慢而疼、长矛=直线突刺、双刀=快而脆），每个新怪免教学。前提是数值分化与视觉分化必须配对设计，敌人定义表把两边写在同一行天然强制配对。

实现路径按 game-driven 选：**烘焙变体**（Blender 里导出组合 glTF，零代码，先用）→ 变体组合爆炸时（3 本体 × 4 武器 = 12 文件）才提炼**运行时插槽**（挂接系统一张中等卡）——「第二次复用才提炼」的时机判断样例。

已预见坑：跨套装尺度灾难（不同作者单位/朝向不同 → 加载归一化 + 每武器一行锚点偏移配置）；骨骼命名统一（Mixamo 系 `mixamorig:RightHand` 天然统一，采购 Mixamo 系的隐藏红利）。

### 平涂/卡通/手绘三流派（low-poly 语境）

- **纯色平涂**：每部件一个纯色，无贴图，光照出体积感——采购匹配最好（Kenney/Quaternius 大量此风）、AI 生成容错最高（没有细节=没有细节错误）、技术零门槛（Bevy 标准材质直接支持）。**推荐起点**
- **卡通着色（toon）**：观感更好但需定制 toon shading 材质（中等渲染卡），CC0 模型风格易和 toon 渲染打架。当阶段 4 升级项
- **手绘贴图**：艺术家路线，无美术团队直接排除

调色板是风格统一的真正引擎：色彩即玩法语言（暖玩家/冷环境/高亮可交互，带理由写进风格圣经）；量化脚本把「风格漂移」这个不可数字化问题转成可数字化验收（超色板颜色 → 量化到最近色 + 日志报警）；AI 生成 prompt 里写死 hex + 生成后量化 = 双层保险。

风格圣经五段：基调（一句话+3 参考图）/ 调色板（hex+用途+理由）/ 造型语言（基本体组合规则）/ 比例（头身比约定，比细节更抓眼球）/ 禁止项（写实纹理、超色板颜色等反面清单）。

### 成本分布（行业经验形状）

角色（含动画）~40% > 环境 ~20% > VFX ~15% ≈ 音频 ~15%（常被低估，打击感一半在音效）> UI ~10%。推论：角色是大头但恰是 Mixamo+CC0 覆盖最好的品类——「无美术」约束打在了最可外包的位置。
