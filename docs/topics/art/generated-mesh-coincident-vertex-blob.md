# 图生 3D 网格的重合顶点 blob

## 现象

对 AI 图生 3D（混元/Rodin 类）产出的单网格模型做部件拆分时：

- 边连通分析：766 个互不连通的「岛」（看似大量 UV 碎片）；
- 按位置焊接（1e-4 容差）：**整个 9625 顶点网格坍缩成 1 个连通件**；
- 精确位相等焊接：同样坍缩成 1 件——存在 4711 对**位级相同**顶点；
- 按包围盒做面级空间选择：目标区域 y 向顶点分布 0.298→0.353 连续无间隙，与相邻部件（贴在一起的轨道）不可分。

## 根因

生成器为了 UV/法线把顶点按面拆分（同一位置多个顶点副本），同时**相邻部件在接触处共享位级相同坐标**——整套网格经重合点链成单一 blob。「岛多」与「全连通」同时成立：前者是索引拓扑视角，后者是位置视角。任何依赖「位置相近=同一部件」的启发式（焊接、空间盒选）都会被这条链劫持。

## 解决

部件认定退回**边连通岛 + bbox 种子**：目标件的边连通岛 bbox 与取证渲染确认的位置钉死匹配（容差 0.01），唯一命中才动刀，多命中/零命中即退出（手术脚本 exit 2）。岛内完整性由视觉验收兜底（隔离渲染 + 与源版本拓扑逐项对比：顶点/面/开放边数全同 = 零损伤拆分）。

## 反思

「碎岛多所以需要位置焊接」是先验想象——取证渲染（染色隔离）显示目标件单岛即完整，焊接防的是不存在的问题，反而引入吞模型的真问题。分离策略要跟着**证据**（渲染看到的形态）走，不是跟着拓扑统计走。
