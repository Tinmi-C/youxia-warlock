# raw — 原始资料层

**只读、不可变**的素材仓库：文章、论文、链接、聊天记录、图片、数据文件等。这是整个知识体系的**事实来源**，AI 只读取、不修改。

## 为什么要有这一层

编译后的知识（`topics/`）是 AI 提炼的结果，可能带失真或幻觉。`raw/` 保留原始材料，让一切结论都能回溯到源头。

## 怎么用

1. 把值得长期保存的资料放进这里（浏览器可用 Obsidian Web Clipper 转 markdown，或手动粘贴）。
2. 目录结构可自定义，按来源/主题分都行。
3. 对 AI 说"阅读 `raw/` 新增的文件，编译知识"，它会按 `AGENTS.md` 的摄入流程处理。

## 分类建议

- `articles/` — 收藏的文章
- `papers/` — 论文
- `links/` — 待整理的链接与摘录
- `chats/` — 有参考价值的对话记录
