# _private — 个人笔记区（不推送团队仓库）

此目录**已被 git 忽略**（见 `.gitignore`：只忽略内容、保留本说明文件）。里面的内容只存在于你自己的本地，**不会提交到团队远程仓库，同事也 pull 不到**。

## 用法

- 个人草稿、私人 TODO、只对自己有用的笔记 → 放这里
- 想分享给团队的内容 → 移到 `topics/` 对应主题，更新 `_index.md` 和 `MOC.md`
- Obsidian 仍会显示这个目录（本地文件），只是 git 不管它

## 注意

- 别把团队内容误放进来（团队内容是共享资产）
- 需要备份个人笔记？自己对这个目录单独建 git 仓库或定期导出
