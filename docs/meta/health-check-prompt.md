# 健康检查提示词

定期（每批摄入后 / 每周）让 Agent 执行。直接复制给任意 Agent：

> 检查当前知识库的死链接、孤立页面、重复页面、无来源结论、潜在冲突、过期内容、待审核页面和索引漂移。生成报告，并区分「可以自动修复」和「需要人工判断」的问题。未经确认，不要改动存在事实冲突的内容。

## 检查清单

- 死链接：`[[...]]` 指向不存在的页面
- 孤立页面：除 MOC/index 外没有任何页面链接到它
- 重复页面：同一主题多处重复
- 无来源结论：结论没有 raw 或 wiki 依据
- 潜在冲突：两个页面说法矛盾
- 过期内容：`status: draft` 长期未定稿、结论已被推翻
- 待审核：frontmatter 缺元信息
- 索引漂移：`MOC.md` 与各 `_index.md` 没跟上实际文件

## 执行后

- 报告写进 `log.md`
- 可自动修复的 → 修复并说明
- 需人工判断的 → 列出，等人确认
