# legion（军团战争图）

> 第三张 warbase 验收图：多人对抗半区（2v2）。本项目是**基底复用效率的
> 度量对象**——每增量记录行数/耗时/新洞（[docs/kpi.md](docs/kpi.md)），
> 与 rts-lab 对比出复用效率曲线（ADR-0019）。
> 项目级 AI 约定见 [AGENTS.md](AGENTS.md)；需求锚点见 vault
> `docs/topics/game-design/legion-td-proposal.md`。

## 快速开始

```bash
cargo run -p legion -j4          # 真机灰盒（共享机纪律：合并到必要节点跑）
cargo test -p legion -j4         # 本项目回归（headless，27 测）
# 离屏 GPU 截图（取证，须在可独占 GPU 时跑）：
cargo test -p legion --test ui_shots -j4 -- --ignored --nocapture
cargo test --workspace -j4       # 一击全量回归（增量门禁）
```

## 玩法（LG2 起可玩，LG3 起有完整 HUD）

- 建造期 30 秒：左键点自家布阵格选中 → 数字键 1-6 或点击商店卡雇兵
  （def 表即价格）→ 兵落格上；悬停商店卡时自家空闲布阵格金色高亮预览。
- 建造期可发兵（G 键或点击发兵钮）：花钱给本路对家注入下一回合的额外兵
  （25 金起，同目标每发 +10%，递增价在发兵入口实时预览）；
  发出的兵战斗期从己方布阵区出征攻向对家，打穿对家底线 = 对家命 -1 +
  出资方击穿赏金 +5。
- 战斗期自动：雇佣兵沿路 AttackMove 至对家底线，路上自动交战；抵达底线=漏怪，对家命 -1。
- 命 20 起扣尽出局；场上只剩一队战力时 LastTeamStanding 定胜负。
- 回合结算：+50 金 + 击杀赏金（横幅显示「第 N 回合结算 · +50 金」）；
  20 回合封顶 → 剩余命数多者胜（平数平局，横幅显示「平局 ——」）。

## 操作

| 键 | 动作 |
|---|---|
| 左键 | 选中布阵格/单位；点击商店卡/发兵钮购买（Custom action 派发） |
| 1-6 | 建造期：往选中格雇佣对应兵种（cheap/swarm/tank/ranged/aoe/support） |
| G | 建造期：给本路对家发 1 个 swarm（与点击发兵钮等价） |
| Space | 建造期秒进战斗期（跳过等待） |

## UI（LG3：方案 A「铁金条约」套用）

六面板（loop-td `systems/panels.rs` 模式照搬，主题=Plan-A RON + 共享 CJK 字体两件套，
换肤复用成本见 kpi.md LG3 行）：①HUD 资源条（金/人口/回合/倒计时，TL）；
②命数板（四家，队色 P0P2 蓝 / P1P3 红，TR）；③雇佣兵商店卡（6 兵种价格/人口/攻甲型，BC）；
④布阵格高亮（悬停商店卡 → 自家空闲格金色发光片预览）；
⑤发兵入口（目标 + 本发/下一发/再下发递增价，BR）；⑥回合横幅（建造/战斗/结算三态 + 终局，TC）。
离屏截图取证：`docs/img/01..05-*.png`（全景/商店卡/命数板/横幅/结算横幅）。
