# 风格圣经（Style Bible）v0 — Wave Survival

> 状态：**v0 草案，待团队 review**（2026-08-27 起草）。
> 本文档是全部美术决策的唯一裁判：采购、AI 生成、占位图、UI 用色，一律对着它检查。
> 修订规则：任何新决策（含 review 时的改动）直接改正文并保留「为什么」——判断沉淀成文字才可复用。

## 0. 使用方式

- 新资产入库前必过：色板量化 / 造型语言 / 比例 / 禁止项 四条检查（AI 生成件同样适用）。
- 洗白流水线（卡 17 `normalize.py`）的色板 json 以本文档第 2 节为唯一事实来源。
- 「统一但粗糙」远胜「局部精致但互相打架」——本圣经管的是资产之间的**关系**，不是单件精致度。

## 1. 基调

**明快平涂 low-poly；读法参考 Crossy Road × Vampire Survivors。**

- 美术第一任务是可读性：同屏 50+ 实体时，0.2 秒分辨 我 / 怪 / 掉落 / 危险。
- 参考图：待 review 时三人各贴 2-3 张进评审笔记，取交集后钉死在这一节。

## 2. 调色板（10 色 v0 提案，hex 待 review）

色彩即玩法语言——每个色带用途入场，不许挪用：

| Hex | 色 | 用途 | 理由 |
|-----|-----|------|------|
| `#E8A33D` | 暖橙 | 玩家主色 | 暖=玩家（品类惯例，一眼锁定自己） |
| `#F5F0E6` | 米白 | 玩家副色 / UI 文字 | 中性提亮，不与任何语义色抢 |
| `#7AA25C` | 族绿 | 怪物基础槽位 green | 冷偏自然色 = 敌意但非致命 |
| `#B03A2E` | 深红 | 怪物精英槽位 red | 饱和红 = 又一档威胁等级 |
| `#6B7F8A` | 冷灰蓝 | 地面主体 | 冷=环境，后退感，衬托暖色单位 |
| `#4A6B5D` | 深绿 | 环境点缀物 | 与族绿拉开明度防混淆 |
| `#FFD23F` | 亮金 | 掉落 / 可交互高亮 | 全场最亮，奖励路径永远醒目 |
| `#D64541` | 危险红 | 伤害区域 / 危险预告 | 与精英红同族不同档，语义连续 |
| `#1B2430` | 深墨蓝 | UI 面板底 | 压住画面，让游戏世界更亮 |
| `#3A3F4A` | 暗灰 | 阴影 / 次级 UI | 只做「退后」，不携带语义 |

量化规则（双保险）：资产入库前 normalize.py 强制把所有材质基色量化到本表最近色；AI 生成 prompt 里写死 hex。两层各拦一次。

## 3. 造型语言

- **基本体组合**：形体由盒子/圆柱/球拼装感构成，允许看见「零件感」；不做有机曲面堆砌。
- **平涂无贴图**：每部件一个纯色，体积感交给光照；不用纹理贴图（Bevy 标准材质直接支持，零渲染卡）。
- **剪影密度**：一个资产的轮廓要有 2-3 个可辨识凸起（角/肩/武器），但整体轮廓复杂度不超过玩家模型——敌人读起来要比玩家「简单一档」。

## 4. 比例

- 目标区间：**2~3 头身**（Q 版区间，CC0 采购池天然落在这里）。
- 精确数值**暂不钉死**：等卡 16 出图册、人做完 20 选 1 后，按选中件的实际比例回填本节并从此锁死。
- 已锁死的配套约定：玩家与怪物族共享同一身高标尺（怪物身高由敌人定义表 scale 档位派生，不另立标尺）。

## 5. 禁止项（反面清单）

- ❌ 写实纹理 / 材质（木头纹理、金属划痕、布料褶皱）
- ❌ 超色板颜色（含渐变中间色——量化会打回）
- ❌ 单资产偷偷精致（一个 4k 贴图的宝箱混在一群平涂里 = 打架）
- ❌ 非人形怪物（v1 结构性条款，见第 6 节）
- ❌ 新增第 11 个色（先改本表再谈新色）

## 6. 结构性条款（本轮管线讨论新增，2026-08-27）

1. **人形约束**：v1 全部怪物为人形 biped。这不是审美妥协——它是「AI 生成 → Mixamo 自动绑骨 → 动画白拿」整条链成立的结构性前提；非人形没有任何动画捷径。
2. **族级批次生产**：美术生产单位是「族」不是「单怪」（基础体型 × 色槽 × 缩放档 × 武器件一次成批）；单怪需求 = 定义表加一行，不触发新生产。
3. **双保险量化**：生成端 prompt 写死 hex（第一道） + 入库端 normalize 量化（第二道）。风格漂移靠管线兜住，不靠生成模型的自觉。

## 7. 评审笔记约定（20 选 1 的落地形式）

- 每批候选资产：卡 16 出图册 PNG → 建一篇 Obsidian 评审笔记（放 `docs/` 对应主题或项目 docs）贴图。
- 人的验收动作只有一件事：**选一个并写出为什么**（「第 3 张对在低饱和/剪影更清楚」）。
- 「为什么」是本轮产出的真正资产：直接回写进第 3/4 节的规则，成为下一批的硬约束。

## 8. 命名与目录约定

- 模型文件：snake_case 语义名（`goblin.glb` / `goblin_club.glb`），放 `assets/models/`。
- 动画 clip 名统一：`idle` / `run` / `attack` / `death`（套装自带 clip 若不同名，洗白阶段重命名）。
- 骨骼约定：优先 Mixamo 系命名（`mixamorig:*`），为未来武器插槽留映射红利。
