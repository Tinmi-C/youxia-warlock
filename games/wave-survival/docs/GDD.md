# GDD — Wave Survival（波次生存）

> 2026-08-25 立项。基于 Bevy 0.19 的专业流程首个游戏（垂直切片优先）。
> 技术方案遵循团队约定：客观→插件引用；主观→自研（见 `docs/topics/engine/bevy-plugin-and-code-reuse.md`）。
> 玩法数值继承 m2-bevy 已验证的设计（波次公式/伤害/冷却——那是团队设计资产）。

## 一句话玩法

操控角色在**波次递增**的怪物进攻中生存，每波更强，看你能撑到第几波。

## 核心循环

```
生存 → 清怪（近战挥砍 + Shift 范围斩）→ 波间喘息（3 秒）→ 更强的一波 →（循环）→ 死亡 → GameOver → R 重开
```

## 目标平台

- 桌面（开发：Mac；无头验证：Linux VM + Xvfb/lavapipe）
- 后续可选：Web（bevy_webgl2）

## 范围

**做**：
- 3D 场景：玩家 + 怪物 + 地面（骨骼动画角色，glTF）
- 移动：WASD（手感自研薄层，帧率无关）
- 近战挥砍（Attack）+ 范围斩 Nova（Shift，粒子特效）
- 波次系统（三态：战斗中/波间/刷波，公式见下）
- 掉落拾取（回血）
- UI：血条 / 波次格子 / 冷却条 / 暂停 / GameOver（bevy_ui）
- 调试：bevy_egui 实时调参面板 + 日志仪表 + F12 截图
- 物理：bevy_rapier3d（碰撞/受击判定）

**不做**（v1）：技能树、多角色、联网、存档、移动端、剧情、音频合成（音效后置）

## 验收标准（分阶段）

- **垂直切片**：能完整玩一局（出生→移动→刷怪→击杀→死亡→重开），数值对齐上表
- **玩法深化**：Nova/粒子/敌人分化，每功能有卡 + 测试
- **表现层**：骨骼动画 + UI 正式化 + 音效（后置），ADR-0004 → accepted
- **打磨**：连续玩 N 局无崩溃，难度曲线有梯度

### 美术（阶段 3 前置，详见 docs/topics/game-design/art-pipeline-human-ai-division.md）

- [工具卡 → 卡17 草案] 资产预览+洗白流水线：**改走 Blender 无头脚本**（`tools/art/turntable.py` 批量出图册 PNG + meta.json：包围盒→碰撞半径候选、clip 清单、面数；`normalize.py` 洗白：Y-up/脚底原点/身高归一/色板量化）；**否决 Bevy 自研 bin**（Blender 反正是 FBX→glTF 必经工具，一套脚本两个职责）。G 键全资产展厅（AssetGallery）维持后置终审用
- [规范] 风格圣经 + 调色板约定：风格定向 low-poly 卡通；全项目限定 8-12 色调色板（所有资产对着它检查，风格统一靠锁色而非靠画功）；评审记录落 Obsidian 评审笔记（带图 + 说清为什么）；**v0 已落地：docs/style-bible.md（含结构三条款：人形约束 / 族级批次生产 / 双保险量化），10 色 hex 待 review**
- [采购策略] 按套装采购，不按单品：锁定 Kenney/Quaternius 各一个怪包 + 一个环境包做基底（同源 = 造型语言天然统一，量化管颜色管不住形状）；AI 生成角色不直接入库，只作套装新成员粗坯，须满足风格圣经四条（比例/基本体构成/色板/剪影密度）才入族；动画 Mixamo 自动绑骨 + 动作库；【2026-08-27 修正】角色线「AI 生成主力 vs 套装主力」不由拍脑袋定——卡 18 对比 spike 用数据裁决后回写本条（环境/道具仍套装采购）
- [变体派生] 一个基础模型撑一族敌人：换色板槽位 + 缩放 + 部件替换（绿 1.0x 小怪 / 红 1.3x 精英）；与 ECS 数值分化对称设计（快而脆↔细长绿 / 慢而硬↔粗壮红），落地形态 = spawn 读「敌人定义表」（组件数值 + 视觉参数一行）——「新怪 = 新组件组合」规则在美术层的延伸
- [自动化] 占位图系统：spawn 引用语义名（goblin.glb），文件缺失时程序化生成占位 + 日志提示「用了占位」——真资产放进目录自动换上，日志即美术进度仪表盘
