# GDD — Wave Survival（波次生存）

> 2026-08-25 立项。基于 Bevy 0.19 的专业流程首个游戏（垂直切片优先）。
> 技术方案遵循团队约定：客观→插件引用；主观→自研（见 `docs/topics/engine/bevy-plugin-and-code-reuse.md`）。
> 玩法数值继承 m2-bevy 已验证的设计（波次公式/伤害/冷却——那是团队设计资产）。

## 一句话玩法

操控角色在**波次递增**的怪物进攻中生存，每波更强，看你能撑到第几波。

## 核心循环

```
生存 → 清怪（近战挥砍 + Shift 范围斩）→ 波间喘息（3 秒）→ 更强的一波 →（循环）→ 死亡 → GameOver → R 重开
```

## 目标平台

- 桌面（开发：Mac；无头验证：Linux VM + Xvfb/lavapipe）
- 后续可选：Web（bevy_webgl2）

## 范围

**做**：
- 3D 场景：玩家 + 怪物 + 地面（骨骼动画角色，glTF）
- 移动：WASD（手感自研薄层，帧率无关）
- 近战挥砍（Attack）+ 范围斩 Nova（Shift，粒子特效）
- 波次系统（三态：战斗中/波间/刷波，公式见下）
- 掉落拾取（回血）
- UI：血条 / 波次格子 / 冷却条 / 暂停 / GameOver（bevy_ui）
- 调试：bevy_egui 实时调参面板 + 日志仪表 + F12 截图
- 物理：bevy_rapier3d（碰撞/受击判定）

**不做**（v1）：技能树、多角色、联网、存档、移动端、剧情、音频合成（音效后置）

## 玩法数值（继承 m2 已验证设计，照抄）

| 项 | 公式/值 | 来源 |
|----|---------|------|
| 波次数量 | `2 + n` | WaveSystem 卡 |
| 波次速度 | `1.1 + 0.08n` | WaveSystem 卡 |
| 波次血量 | `30 × (1 + 0.4n)` | WaveSystem 卡 |
| 波间喘息 | 3 秒 | WaveSystem 卡 |
| 近战挥砍 | 0.9 内 −34 / 1.5 外 −0 / 冷却 0.45s | CombatSystem 卡 |
| 范围斩 Nova | 半径 1.6 / 伤害 60 / CD 5s | NovaSystem 卡 |
| 玩家移动 | speed 可调（默认 4.0，手感待调） | 自研 |
| 死亡 | GameOver → 显示 survived to wave N → R 重开 | m2 |

## 验收标准（分阶段）

- **垂直切片**：能完整玩一局（出生→移动→刷怪→击杀→死亡→重开），数值对齐上表
- **玩法深化**：Nova/粒子/敌人分化，每功能有卡 + 测试
- **表现层**：骨骼动画 + UI 正式化 + 音效（后置），ADR-0004 → accepted
- **打磨**：连续玩 N 局无崩溃，难度曲线有梯度
