## 1. 一句话定位

**看"游戏里的资产"的工具 + 玩法小功能的试验台**。资产进了游戏之后的一切查看——组合形态、数值、动作、
来源与版本；以及把两个（类）角色摆上台让它们**用游戏的真实逻辑**互相打，看动作与结算。
分工不变：单资产入库预览归岩库；运行时全量体验归实机；本工具管中间层。

## 2. 谁在什么时候用

- 开发日常：看资产效果、调数值、验动作（最高频）
- **玩法调试：新攻击/受击/技能逻辑上线前后，快速摆一场小对决观察**（新增，高频）
- 资产升级时：新旧对比决定升不升
- 组合设计时：看部件装配关系与来源
- 偶尔：新成员认识项目资产

## 3. 需求清单

### N1 目录与查找（必须，已拍板）

资产只增不减：搜索（名称/标签子串即时过滤，列表画廊同步）、分类折叠浏览、资产卡基本信息
（名字/类型/来源/版本/体积）、大库分页不崩。验收：100+ 资产 ≤3 次输入找到目标。

### N2 操作面板（必须，已拍板）

面板 = 工具唯一完整操作入口，**现有全部功能收编**（浏览/画廊/动画/相机）；新增动作播放控制
（选/暂停/速度/循环单次/逐帧）、视角重置、转台、帮助。验收：无提示 5 分钟走通全流程。

### N3 岩库联动（已拍板：回流暂缓）

- **看来源**（"这东西哪来的"）：条目显示岩库资产 id+版本；组合拆开逐件看来源。
- **升级对比**（"升不升"）：新旧版本以游戏组合形态同台对比。
- 提醒回流：暂缓（触发条件到再立）。反向追溯：远期。
- 不做：浏览岩库未接入资产（岩库自己的活）。

### N4 特效与扩展性（已拍板：本期零功能，设计留位）

资产类型可扩展（将来加"特效"类 = 多一类）、面板分区可扩展、资产卡字段可扩展——不推倒重来。

### N5 资产组合（新增——"组合这一步是怎样的"）

组合 = 游戏把多个资产装配成一个整体（例：岩库的塔身 + 岩库的床弩 + 游戏侧装配规则 = 弩塔）。
**组合的定义权在游戏**（哪些部件、怎么装，是游戏逻辑）；工具负责把组合的三个层次摆出来：

| 步 | 用户能做什么 | 说明 |
|---|---|---|
| ① 看整体 | 组合作为一条目展示完整形态（已有：弩塔条目） | 组合体和单资产在目录里平级 |
| ② 看拆解 | 部件清单逐件看：点清单里某件 → 该件高亮、其余半透明；每件显示自己的来源（岩库 id+版本） | 回答"它由什么组成"；与 N3 看来源同一张卡 |
| ③ 看装配（远期） | 装配参数可视可调（如挂点高度、朝向），调完即见效果——服务"调参不用改代码重编译"的轻量场景 | 观感/手感类常量的可视化调节；先立需求，实现另行评估 |

验收（①②期）：弩塔条目能拆出塔身/床弩两件、逐件点亮与溯源；③ 待评估后再定验收。

### N6 玩法小测试场 · 对决场（新增——本版核心增量）

**目的：测小功能玩法。** 例：一个角色攻击另一个角色——同时观察攻击动作、受击动作、攻击逻辑（伤害/时序）。
对标（调研结论）：Dota2 演示模式的 Target Dummy（靶子记录**总伤害 / 每秒均伤 / 最近一次命中**）；
格斗游戏训练模式的**木桩行为切换**（站桩/防御/…）与**帧数据/时序显示**。

**选角方式**（"如何选这两个角色"——采用格斗游戏训练模式的 A/B 双选范式）：

- **主角槽 A + 靶子槽 B**：各自从同一资产列表里选（支持搜索，复用 N1）；面板显示两槽，点槽即弹选择；
- A/B 可一键互换（换攻守视角）；靶子可加到多个（分期：先 1 个，再多）；
- 选完即上场：两角色同台面对面站立。

**编排与控制**：

- 开始 / 暂停 / 重置（复用 N2 的时间控制：慢放、逐帧——看受击动作的起止帧）；
- 靶子行为预设：站桩 / 定距走动 /（分期）反击——对标格斗木桩的行为档位；
- 自动循环攻击（攻速由角色数据决定），或单次触发逐发看。

**观察仪表**（靶子就是仪表，抄 Dota Target Dummy 的账本）：

- 伤害飘字 + 血条（受击方）；
- 靶子账本：**总伤害 / 每秒均伤 / 最近一次命中值**，面板实时；
- 命中时序：攻击动作帧 ↔ 命中结算帧的对应（配合逐帧，验"动画与逻辑对没对齐"）；
- 日志：每次命中的完整结算记录（伤害构成、护甲、暴击类修正——字段由游戏提供）。

**边界（工具不造假逻辑——"测真"的关键）**：攻击逻辑用**游戏自己的真实管线**（warden 就是塔开火→
弹体→命中结算那套）；工具提供舞台、选角、编排、仪表，不重新实现一份攻击。游戏侧把"可登场的角色 +
其攻击/受击行为"注册进工具即可（对 warden 首个用例 = 塔 vs 敌）。

验收草案：选 A=弓箭手塔、B=盾兵怪 → 开打 → 可见开火动画/弩转向/弹体飞行/命中闪白与扣血；
面板账本总伤/DPS 随打累计；0.25x 慢放下逐帧看到"命中帧=受击闪白帧"；重置后账本清零、血量回满。
