## 1. 一句话定位

**看"游戏里的资产"的工具**：资产进了游戏之后的一切查看——组合形态、游戏数值、动作表现、来源与版本。
分工：单个资产的入库预览归岩库（已支持）；本工具不重复它，专做"资产在游戏语境里长什么样"。

典型例子：弩 + 塔的组合。弩和塔是两个岩库资产，但"装在一起、挂在什么高度、转向/后坐什么感觉、数值几何"——
只有本工具能看。

## 2. 谁在什么时候用

- 开发日常：美术资产接入后看效果、调数值、验动作（最高频）
- 资产升级时：决定"岩库新版要不要升进游戏"
- 组合设计时：看部件装配关系与来源
- 偶尔：新成员快速认识项目全部资产

## 3. 需求清单

### N1 目录与查找（必须——资产只增不减）

资产数量会从现在的十几个涨到几百个，翻列表必然失效。

- **搜索**：输入名字（中/英/拼音首字母都认）即时过滤，列表和画廊同步生效；
- **分类**：塔 / 怪 / 组合 / …… 分组继续可用，可折叠；
- **资产卡信息**：每个资产随时能看到——名字、类型、来源（岩库？游戏自制？）、版本、体积；
- **大库不崩**：资产上百后画廊自动分页或分组铺开，浏览依然顺畅。
- 验收口径：100+ 资产时，找到任一目标 ≤ 3 次输入内。

### N2 操作面板（必须——工具的唯一完整操作入口）

**现有全部功能收进面板**（浏览切换 / 画廊与聚焦 / 动作选择 / 相机环绕缩放 / 重置），做到"不看文档、
不背快捷键也能完成所有操作"；快捷键保留作速记。面板随当前资产显示它的全部信息（数值 / 来源 / 动作）。

新增操作能力：

| 类别 | 操作 |
|---|---|
| 动作 | 选动作、播放 / 暂停、速度调节（慢放看细节）、单次 / 循环、逐帧步进 |
| 视角 | 一键回默认视角、转台自转（腾手看细节） |
| 观察辅助（可后置） | 线框 / 骨骼 / 包围盒显示开关 |

- 验收口径：接手的人在无提示情况下，5 分钟内完成"找到资产→播放指定动作→慢放逐帧观察→看来源版本"全流程。

### N3 岩库联动（直白版——四个场景）

**联动一【看来源】**：任意资产身上能看到"我来自岩库哪个资产、哪个版本"；游戏拼的组合（如弩+塔）
能拆开看到每一件的来源。——回答"**这东西哪来的**"。

**联动二【提醒回流】**：游戏里自己新做 / 改过的资产，在工具里标出"还没回流岩库"。——回答"**我欠岩库什么**"
（防止自制资产散落游戏仓库里忘记入库）。

**联动三【升级对比】**：岩库资产出新版本时，在本工具里把新旧版本**以游戏里的组合形态**摆在一起对比，
再决定升不升。——回答"**升不升**"（呼应"升级 = 改清单重跑"的既有流程）。

**联动四【反向追溯】（远期，暂不做）**：岩库那边反过来能看到"这个资产被哪些游戏怎么用了"。等组合数量多、
且岩库愿意扩展时再议。

**明确不做**：在本工具里浏览岩库中尚未接入游戏的资产——那是岩库自己的预览该干的活，不重复。

### N4 特效与扩展性（本期不做功能，设计必须留位）

- 本期不做任何特效相关功能（负责人已拍板暂缓）；
- 但本期设计要"考虑全面"：资产类型可扩展（今天塔/怪/组合，明天加"特效"一类不用推倒）、
  操作面板可扩展（将来加"播放特效预览"类的操作有位置放）、资产卡信息可扩展（加绑定事件/音效等字段不挤爆）。
- 验收口径：将来新增一种资产类型，不需要改工具的骨架，只是"多一类"。

## 4. 分期建议

| 期 | 内容 | 理由 |
|---|---|---|
| **P1** | N2 操作面板（收纳现有 + 动作控制）＋ N1 搜索与资产卡（**并行**，已拍板） | 每天都用，最高频 |
| **P2** | N3 联动一（看来源）+ 联动三（升级对比） | 资产纪律；回流提醒暂缓（已拍板） |

| 远期 | 联动四；特效（届时按 N4 预留位接入）；回流提醒（触发条件到再立） | 条件成熟再动 |
