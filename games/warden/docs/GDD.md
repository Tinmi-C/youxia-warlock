# GDD — Warden（塔防）

> 立项日期：2026-08-25。基于 Bevy 0.19 + AI 协作工作流（见 `AGENTS.md`）。
> **规则与全部数值的唯一依据是 `docs/requirements.md`**（设计层源文件，2026-09-03 录入）。本文件是**产品总览**：
> 定位、核心循环、范围、关键设计决策、验收信号、垂直切片。不要在此重复 requirements 的数值表，避免两处漂移。

## 一句话定位

每局随机给塔、塔靠多来源获取、可融合进化的塔防：波次间经营资源、投资布阵，死了重开但局间解锁的成长保留。

## 核心循环（双速节奏）

```
波次间（慢思考·经营）              波次中（快反应·战斗）
├─ 买塔 / 融合塔 / 决定铺量或堆质    ├─ 敌人沿 L 形路径推进
├─ 三选一强化 / 赌掉落              ├─ 塔自动开火
└─ 手动点「开始下一波」             └─ 漏怪掉基地血，波次结束结算
```

## 目标平台

- 桌面（开发：Mac；无头验证：Linux VM + Xvfb/lavapipe）
- 后续可选：Web（bevy_webgl2）

## 范围

**做（MVP，见 requirements §2 全量 + 本节垂直切片）**：
- L 形地图 + 1 路径 + 基地（血 10）；8 塔位（刻意稀缺）
- 4 基础塔 + 4 融合配方；6 敌人 + 10 波（1 精英 + 1 BOSS）
- 5 种塔来源（开局手牌/商店/掉落/三选一/融合）
- 波次间三选一；极简 Meta（1 条解锁链）；占位美术（方块+色块）

**不做（砍掉，别碰）**：
- 英雄单位、联机、节点地图、复杂 Meta 树、音效、利息、飞行怪、多套克制
- **技能系统**（主动/被动/光环）：明确暂缓，灰盒**不要实现**

## 关键设计决策（别改错）

| 决策 | 铁律 | 理由 |
|------|------|------|
| 双速节奏 | 波次进行中**锁建造**，只有波次间开放经营菜单 | 双速节奏成立的前提（requirements §3） |
| 融合收益 | 融合塔 DPS ≈ 两原塔之和的 90%–110%，价值 = **换定位 + 腾塔位** | 防「融合无人用」/「融合太强」两个失败信号（§7） |
| 克制 | 只做「物理 vs 魔法」一维物理护甲 | MVP 防蔓延（§6） |
| 经济 | 不做利息 | 防攒钱不花（§11） |
| 塔位 | 8 个，刻意稀缺 | 逼融合腾位（§4） |
| Meta | 对症下药：缺输出就解锁输出 | 让玩家觉得"下次能赢"（§13） |

## 验收标准

**失败信号**（任意一条出现 = 核心循环不成立，回头改设计）：决策摆烂 / 选择无重量 / 融合无人用 / 融合太强 / 归因运气。
**成功信号**（越多越成立）：波次间真纠结 / 融合被主动用 / 每局不同 / 失败想重开。
（每条的具体观察口径见 requirements §15；调参入口见 requirements §14 速查表。）

## 垂直切片（灰盒跑通 = 能完整玩一局）

> 「能玩一局」= 造塔阻挡波次、能体验 **慢思考（经营/融合/三选一）↔ 快反应（战斗）** 的双速节奏，
> 并让第 15 节的成功信号可被观察到。范围：requirements「做」清单的**全部 MVP**。
> 实现按能力卡拆（见 `docs/capability-cards.md` 卡路书），首条可玩闭合 = 单塔单波（见「首条可玩闭合」）。

**首条可玩闭合（最小一行，先跑起来再叠加）**：L 路径 + 基地 + 8 塔位 → 买 1 座塔放置 → 敌人沿路径推进 → 塔自动开火 → 命中扣血/漏怪扣基地血 → 金币赚/花 → 波次推进。这段验证「双速节奏 + 战斗」成立。

**随后补核心乐趣**：融合（同类型升级 + 配方）、三选一、5 种塔来源（含商店保底、掉落、开局手牌）、Meta 解锁链。
