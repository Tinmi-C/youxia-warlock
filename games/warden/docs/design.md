# Warden UI 设计基线（ui-polish 落盘 · 2026-10-11）

> 本文件是 warden 游戏内 UI 的视觉唯一事实源。二次开工直接读它照做，不再重新发明。
> 题材出处：`docs/art-direction.md` D1 晴昼要塞（上午斜阳 · 白灰石 · 明快肃整 · 可读性铁律）。
> 参照提炼：Kingdom Rush（亮色 TD 的信息布局）+ WC3（石质命令甲板）；参照分析存 `/tmp/ui-polish/`。

## 材质三件套（UI 的白灰石语汇，与 3D 场景同源）

| 材质 | 用途 | 底色 | 缝线/描边 | 文字 |
|---|---|---|---|---|
| 白灰石 Stone | HUD 骨架（顶匾/底甲板/按钮槽底） | `#A8A296` | `#6E695E` | 墨 `#2E2A24` / 亮墨 `#3D372E` |
| 羊皮纸 Parchment | 信息面（军报/三选一/终局/技能小卡） | `#EFE6D0` | `#C9BFA6` | 墨 `#2E2A24` |
| 要塞金 Gold | 交互与强调（金币数字/可用描边/主行动） | `#C9A227` | 压暗 `#8F7318` | 金上墨字 |

状态色（点缀，禁大面积）：警红 `#A93226`（低血量/买不起）、钢蓝 `#3F6180`（法术系角标）。
石面辅助灰阶（各有分工，禁随缘）：石亮 `#C4BEB0`（顶缘阳光线）、石哑 `#8A8478`（不可用底）。

## 禁区（AI 味黑名单 · 本项目版）

- 半透明黑色圆角矩形面板、bevy 默认按钮直出、霓虹紫/荧光绿、三原色条无设计直出。
- 灰阶无分工混用；一处以上高光动效；装饰性渐变。

## 字体与字号阶梯（单家族 Noto Sans SC，UI6 硬约束）

层级靠字重（400/700）+ 字号，不引第二字体（许可与体积约束下的选择）。

| 档 | 字号/字重 | 用途 |
|---|---|---|
| 大数字 | 22 / 700 | 顶匾资源数值 |
| 标题 | 15 / 700 | 军报标题、三选一卡名、终局标题 |
| 按钮 | 13 / 700 | 命令卡按钮主字 |
| 正文 | 13 / 400 | 军报内容、信息区 |
| 标签 | 11 / 400 | 顶匾格标签、提示 |
| 角标 | 9 / 700 | 快捷键徽记 |

## 间距与形状

- 间距只用 4 的倍数（4/8/12/16）。底甲板高 128，按钮槽 108×46，三选一卡 200×88。
- 圆角两档：石件 0（石砌不圆）、羊皮纸卡 3px。无投影（石面深度 = 双层描边 + 顶缘亮线）。
- 石面做法（无 9-slice 资产的过渡态，面板贴图走后续 ART 卡）：底色 Node + 1px 缝线边框 + 顶缘 2px 亮条子节点。

## 布局概念：要塞甲板

```
┌───────────────── 顶匾（石，居中）─────────────────┐
│   金 128        盾 10/10        波 3/10 · 备战   │   ← 标签11px + 大数字22px
└──────────────────────────────────────────────────┘
        ┌─ 军报羊皮纸（备战期独有 · 高光时刻）─┐
        │ 下一波军报  普通×5 · 奖励 +20金      │   ← 开波即收起
        └─────────────────────────────────────┘

┌────────────────────── 底甲板（石，128px）──────────────────────┐
│ 信息区(羊皮纸镶片)   │ 命令卡(石槽按钮阵列 2×4)      │ 控制区    │
│ 待命提示/选中详情    │  [建造108×46]… 快捷键角标     │ 开波(金)  │
└───────────────────────────────────────────────────────────────┘
```

- 高光时刻唯一：备战期军报羊皮纸的揭示（哨卡接军报的瞬间）。战斗与操作反馈的即时声光不受克制约束（游戏 UI 本体）。
- HUD 按"瞄一眼就够"设计：常驻只有顶匾三格 + 底甲板；其余状态信息进信息区或军报。

## 交互状态

- 可用按钮：石槽底 + 金 1px 内描边 + 墨白主字。
- 不可用（战斗锁/买不起）：石哑底 + 去饱和文字；价格字转警红。
- 悬停：石亮描边（不做缩放动效）。
- 选中塔：场上选中环金色（沿用），命令卡出"石槽大图标"态。

## 工程约束

- 颜色/字号/间距/尺寸常量集中在 `src/systems/theme.rs`，UI 代码禁 magic number。
- 高频文本只在内容变化时写回（icu 重排教训，见 hud.rs 注释）。
- 文案双语走既有 l10n 键；新增文案必须双语。
