## 一句话玩法

怪物绕圈循环、漏怪不死、活怪存量施压的塔防：在环旁自由建塔（4 基础 + 3 功能 + 3 英雄塔养成三层），波次自动推进，存量满 50 或 BOSS 超时失败，撑过 30 波胜利（无尽可续）。

## 核心循环

```
局外 Meta 解锁 → 开局（金/木/人口）
局内（波次自动推进，备战与战斗并行）：
  建塔/升级/卖塔（金）· 开天赋/买人口/木换金（木）· 看预告调 counter · 英雄塔加点
  → 怪绕圈 · 漏怪留场（存量+1，绕圈获增益）→ 波次结算（击杀金+波次奖）
失败：存量 ≥ 50 | BOSS 超时；胜利：30 波（无尽可续）
```

## 目标平台

- 桌面（开发：macOS Apple Silicon）；headless 验证走 warbase harness

## 范围

**做（v1）**：单环地图、自由建塔、10 塔（4+3+3）、金/木/人口、攻甲克制、30 波 + 2 限时 BOSS + 无尽、存量失败线 + 绕圈增益、出怪预告、命令卡、Meta、BAL 锚点、迷宫冒烟（SMK1）。

**不做（v1）**：联网、可视化编辑器、剧情、装备/神器、挑战/挖宝、羁绊（后四项 v1.5/v2）。
